# 🏨 Hotel Case Reporting System — คู่มือการใช้งานเซิร์ฟเวอร์ (README)

เอกสารสรุปการติดตั้ง โครงสร้างโฟลเดอร์ และวิธีเปิดใช้งานระบบเว็บแจ้งเคสโรงแรมบน PC เครื่องนี้ (สร้างโดย แอน 🤖)

---

## 📂 โครงสร้างโฟลเดอร์ใน `D:\Ann\`

```text
D:\Ann\
│
├── 📁 app\                  ➔ โค้ดระบบเว็บทั้งหมด (index.html, app.js, styles.css, server.js)
├── 📁 tunnel\               ➔ โปรแกรม Cloudflare Tunnel (cloudflared.exe)
├── 📁 scripts\              ➔ สคริปต์คำสั่งย่อย
│   ├── start-server.bat     ➔ รันเฉพาะเว็บเซิร์ฟเวอร์ Local
│   ├── start-tunnel.bat     ➔ รันเฉพาะอุโมงค์ออนไลน์ Cloudflare
│   └── git-push.bat         ➔ ส่งอัปเดตโค้ดขึ้น GitHub
├── 📁 screenshots\          ➔ ภาพหน้าจอสำหรับใช้อ้างอิง/ช่วยเหลือ
│
├── ⚙️ start-all.bat         ➔ [ดับเบิลคลิกตรงนี้] เปิดเว็บและออนไลน์พร้อมกันทันที
├── 📄 README.md             ➔ ไฟล์คู่มือฉบับนี้
└── 📄 .gitignore            ➔ ป้องกันไฟล์ขนาดใหญ่ไม่ให้ขึ้น Git
```

## 🚀 วิธีเปิดใช้งานระบบ (หลังเปิดคอมพิวเตอร์)

1. เข้าไปที่โฟลเดอร์ **`D:\Ann\`**
2. **ดับเบิลคลิกที่ไฟล์ `start-all.bat`**
3. ระบบจะเปิดหน้าต่างสีดำขึ้นมา 2 หน้าต่าง:
   - **หน้าต่างที่ 1 (Hotel Case Server):** ทำหน้าที่รันเว็บเซิร์ฟเวอร์ในเครื่อง (พอร์ต 8080)
   - **หน้าต่างที่ 2 (Cloudflare Tunnel):** ทำหน้าที่สร้างลิงก์ออนไลน์ออกสู่อินเทอร์เน็ต
4. ในหน้าต่างที่ 2 มองหาบรรทัดที่มีข้อความ:
   ```text
   Your quick Tunnel has been created! Visit it at:
   https://xxxx-xxxx-xxxx.trycloudflare.com
   ```
   นำลิงก์นี้ส่งให้พนักงานหรือเปิดบนโทรศัพท์มือถือได้ทันที

> ⚠️ **ข้อควรระวัง:** ห้ามปิดหน้าต่างสีดำทั้ง 2 บานขณะที่ต้องการให้คนอื่นใช้งาน หากปิดหน้าต่าง ระบบจะหยุดทำงานทันที

## 🌐 ช่องทางการเข้าใช้งานเว็บไซต์

| ช่องทาง | รูปแบบ URL | เหมาะสำหรับ |
| :--- | :--- | :--- |
| **บนเครื่อง PC นี้** | `http://localhost:8080` | ผู้ดูแลระบบที่นั่งหน้าเครื่อง |
| **เครื่องในวง Wi-Fi เดียวกัน** | `http://192.168.9.17:8080` *(หรือตาม IP เครื่อง)* | พนักงานที่ต่อ Wi-Fi วงเดียวกันในโรงแรม |
| **ผ่านอินเทอร์เน็ต / นอกโรงแรม** | `https://xxxx.trycloudflare.com` | พนักงานใช้นอกสถานที่ / ช่างใช้เน็ต 4G/5G |

## ⚙️ ข้อมูลเชิงเทคนิค & ข้อควรจำ

1. **การตั้งค่าคอมพิวเตอร์:**
   - ควรตั้งค่า Windows Power Options ไม่ให้เครื่องเข้าสู่โหมด **Sleep** (`Put the computer to sleep: Never`) เพื่อให้เซิร์ฟเวอร์เปิดบริการได้ตลอด 24 ชม.
2. **การเปลี่ยนลิงก์ออนไลน์ (Quick Tunnel):**
   - ทุกครั้งที่ปิดและเปิด `start-tunnel.bat` ใหม่ Cloudflare จะสุ่ม URL ใหม่ให้เสมอ
   - หากในอนาคตต้องการใช้ชื่อโดเมนคงที่ของตัวเอง (เช่น `hotel.yourdomain.com`) สามารถนำโดเมนมาผูกเข้ากับ Cloudflare ได้
3. **การจัดเก็บข้อมูลเคส:**
   - ปัจจุบันตัวต้นแบบบันทึกข้อมูลไว้ในเบราว์เซอร์ของแต่ละเครื่อง (`localStorage`)
   - สามารถพัฒนาต่อยอดให้บันทึกรวมกันในฐานข้อมูลกลางบน PC เครื่องนี้ (เช่น SQLite) ได้
4. **Git Repository:**
   - เชื่อมต่อไว้ที่: [https://github.com/achar2904/Hotel-test1](https://github.com/achar2904/Hotel-test1)
